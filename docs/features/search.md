# Search

> Moved verbatim out of CLAUDE.md so sessions only read it when they touch this feature.

- Search results (`components/Search.tsx`, `/api/search`): `layoutSearch` (`src/lib/search-intent.ts`, pure, unit tested) decides whether a query is about a title, a person, both or neither (name-match tier with a leading "the/a/an" ignored, TMDB popularity/votes with separate cut-offs for people and titles in `CUT`) and returns the Top result (opened by Enter), the other kind, People and titles, with weak matches folded. People under popularity 1 are hidden unless the full name was typed; marked titles lead only among real name matches, and a marked title that matches as well as the best one becomes the Top result. The API asks `spell.ts` for a spelling fix only when the intent is unclear and uses it only if it gives a clear answer (`exact=1` turns it off). Short queries also fetch page 2 of TMDB's movie/TV search (La La Land is on page 2 of "la la"). Recent searches are kept per device (`tc:recent-searches`), saved when a result is opened.

Collections ("James Bond Collection") come from `searchCollections` with the pop/votes of their biggest film; `pickCollections` shows them below the Top result and hides an unknown franchise (under 1000 votes and popularity 20) unless you have marked one of its films or nothing else matched ("rookie" must open The Rookie, not a Japanese film series).

## Who's that? mode
A segmented control above the box (All | People | Who's that?, `?m=who` / `?m=people` in the URL, nothing else stored). Who's that? (`components/WhoSearch.tsx`, pure `src/lib/who-search.ts`, unit tested) takes a title (Watching series first, or any title via `/api/search?kind=title`), a place (`PositionPicker`, default `startPos`: the episode after the saved place of a Watching series, whole series otherwise, none for a film) and "A name or role you remember". TMDB has no plot text, so only the actor's name and the character match (`matchWho`: every typed word starts a word of the name or role; name first, then role; this episode, main cast, earlier, guests). The people come from `/api/who/roster` (cut server-side at the place, never a later episode) and open with `PersonLink`. Failures show a small note.

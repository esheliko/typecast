# Series, episodes, cast appearances

> Moved verbatim out of CLAUDE.md so sessions only read it when they touch this feature.

- Series: the popup's Episodes section (`components/Episodes.tsx`, `/api/season`) lists every season's episodes with air dates; opening one shows plot, director/writers and guest stars, and "Watched up to here" (`setWatchedUpTo`) saves progress (adding the series as Watching if needed). Cast rows in a series show episode counts and, when opened, which episodes and when (`components/Appearances.tsx`, `/api/appearances`, from TMDB `/credit/{id}`; regulars get seasons only). Anything can open an episode with the `tc:episode` window event. A title opened from a person (`PersonProvider` in `Modal.tsx` adds `?p=`) shows that person's part at the top. The rest of a series cast (`Title.extras`) is hidden rows the cast search finds. Progress is a checklist: each aired episode has a tick (marks everything up to it; ticking your last one steps back; Undo reverts), "Tick whole season", and finishing an ended series offers Mark Watched. Watch next adds "new ep Thursday" (`Facts.nextAir`); the Library's Upcoming section lists next episodes. "You know them from" names the episode for guest parts (`seenIn`, via `getCreditEpisodes` in `enrich`) and leaves out a series until your progress reaches their episodes. Pure helpers in `src/lib/episodes.ts` (unit tested).

Faces per episode: each episode row has a line with up to 3 round guest faces and a short text ("Mara, Tomas +2"). `Episodes.tsx` asks `/api/season-faces?tv&s` (plus the usual line params) once a season has loaded, so the list shows first; it reads the same cached TMDB season as `/api/season` (no extra call) but returns only faces, first names and a count. Pure `episodeFaces` / `facesText` in `src/lib/episode-faces.ts` (unit tested) apply the spoiler line (`allowsEpisode`): episodes after the saved place of a Watching series come back as `hidden` and the row shows a quiet "cast hidden" chip; their guests are never put in the response (series-only: TMDB is not even asked). Not-Watching titles show faces everywhere. Any failure shows no faces. Client cache key includes the line tag, so a moved place refetches.

## Summary rule (moved from CLAUDE.md)

- Episodes section, progress checklist and cast appearances live in `components/Episodes.tsx` / `Appearances.tsx`; pure helpers in `src/lib/episodes.ts` (unit tested); per-episode faces come from `/api/season-faces` (`src/lib/episode-faces.ts`, scoped to the spoiler line). Details: `docs/features/series.md` (read before changing this feature).

## More cast than TMDB (`src/lib/cast-sources.ts`, `src/lib/cast-merge.ts`)

TMDB stays the cast source. TVmaze (`/shows/<id>/cast`, found by IMDb id, else TheTVDB id) and TheTVDB (`/v4/series/<id>/extended` `characters`, actors only; needs env `TVDB_API_KEY`, silently off without it) can only ADD people TMDB's list lacks. Each added name is matched to a TMDB person by exact normalised name (`matchPerson`: actors only, a namesake that is ambiguous is dropped), so the row opens a person page; unmatched names are dropped. They join `Title.extras` (the hidden rows the cast search finds) of the last cast block, in `CastSection`, behind the existing Suspense, raced against 3 s and cached a day (`unstable_cache`), so nothing waits on it in the layout or first paint. Series-level only (name and character, no episode counts), so the spoiler line is not involved. TheTVDB token: the server logs in with the API key itself (`withToken`): renews after 20 days and logs in again on any 401, once. No manual add/override feature by owner decision; IMDb is not used (licensed), Trakt and Wikidata were measured and add nothing.

- Speed: season list, faces and IMDb scores are loaded by `lib/season-load.ts` (module caches). `EpisodesWarm` (mounted by the full title page, outside the popup replay gate) asks for the opening season at the first render so a hard load does not wait for the popup replay; the list then finds the answers. `tmdb()` shares one in-flight request per URL, so the season list and its faces (asked together) cost one TMDB call.
